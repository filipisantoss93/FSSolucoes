# Backlog Geral

Use este arquivo para pendências compartilhadas ou estratégicas. Pendências técnicas específicas devem também existir no repositório do produto correspondente.

## Crítico

- Nenhum item confirmado nesta categoria.

## Alta prioridade

- Documentar os repositórios oficiais de cada produto.
- Mapear ambientes, domínios e integrações em produção.
- Registrar estrutura real de banco e políticas RLS.
- Consolidar auditorias abertas do FS Delivery, FS Fit e FS Orçamentos.
- Confirmar fluxos de assinatura e recebimento de pagamentos.

## Média prioridade

- Criar modelos padronizados de auditoria e ADR.
- Implantar changelog por produto.
- Padronizar checklist de validação antes do deploy.
- Registrar identidade visual e componentes compartilhados.

## Baixa prioridade

- Documentar produtos ainda planejados.
- Avaliar automações de documentação.

## Formato de item

```md
- [ ] Título
  - Produto:
  - Prioridade:
  - Status:
  - Evidência:
  - Próxima ação:
```

Um item só deve ser marcado como concluído quando houver evidência verificável no código, banco, deploy ou documentação.
