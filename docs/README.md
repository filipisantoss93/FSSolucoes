## Regra

Toda decisão importante, auditoria, alteração estrutural, integração, mudança de banco, regra de negócio ou pendência relevante deve ser registrada aqui ou em um arquivo específico do produto.

Não registrar senhas, tokens, chaves privadas, dados bancários completos ou credenciais de produção.
